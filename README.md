# Operação Casamento — uma experiência para Sofia

Mini jogo romântico feito com HTML, CSS e JavaScript puro. Sem dependências, sem áudio, sem servidor.

## Rodar localmente
Abra o `index.html` no navegador, ou, na pasta do projeto:

    python -m http.server 8080

e acesse http://localhost:8080

## Publicar no GitHub Pages
1. Crie um repositório vazio no GitHub (ex.: projeto-sofia).
2. git init && git add . && git commit -m "Operação Casamento"
3. git branch -M main && git remote add origin URL_DO_REPO && git push -u origin main
4. No repositório: Settings > Pages > Branch: main / (root) > Save.
